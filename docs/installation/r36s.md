# R36S Handheld Gaming Console

This guide covers installing tuinix on the R36S handheld gaming console with Allwinner A33 SoC.

!!! warning "Device Variant"
    R36S devices ship with different SoCs. This guide is specifically for the **Allwinner A33** variant (ARM Cortex-A7 quad-core, ARMv7). The Rockchip RK3326 variant has a different boot process and is not yet supported.

## Overview

The R36S is a handheld gaming console that ships with EmuELEC. tuinix can be installed as a replacement system image, providing a minimal NixOS environment.

### Device Specifications

| Feature | Value |
|---------|-------|
| SoC | Allwinner A33 (sun8i family) |
| CPU | ARM Cortex-A7 quad-core |
| Architecture | ARMv7 (32-bit) |
| Display | 3.5" IPS screen |
| Storage | SD card slots (TF1 and TF2) |
| Serial Console | ttyS2 @ 115200 baud |

## Prerequisites

### 1. Extract Stock Firmware

Before building, you must extract firmware from a stock R36S SD card. This firmware is required because:

- The vendor kernel (Linux 3.4.39) includes proprietary display/GPU drivers
- The boot process uses Allwinner-specific U-Boot
- Hardware modules are only compatible with the stock kernel

```bash
# Insert stock R36S SD card (appears as /dev/sdX)
SD=/dev/sdX

# Create firmware directory
mkdir -p firmware/r36s/modules

# Extract bootloader region (MBR + U-Boot)
sudo dd if=$SD of=firmware/r36s/bootloader-region.bin bs=512 count=73728

# Extract boot assets partition
sudo dd if=${SD}2 of=firmware/r36s/boot-assets.img bs=1M

# Extract U-Boot environment
sudo dd if=${SD}5 of=firmware/r36s/uboot-env.bin bs=1M

# Extract kernel boot.img
sudo dd if=${SD}6 of=firmware/r36s/boot.img bs=1M

# Mount SYSTEM and extract kernel modules
sudo mkdir -p /mnt/r36s-emuelec /mnt/r36s-system
sudo mount ${SD}7 /mnt/r36s-emuelec
sudo mount -o loop /mnt/r36s-emuelec/SYSTEM /mnt/r36s-system
sudo cp /mnt/r36s-system/usr/lib/modules/*.ko firmware/r36s/modules/
sudo umount /mnt/r36s-system
sudo umount /mnt/r36s-emuelec
```

### 2. Enable Cross-Architecture Building

Building for armv7l (R36S architecture) on x86_64 requires QEMU binfmt emulation.

Add to your NixOS configuration:

```nix
{
  # Enable QEMU binfmt emulation for cross-architecture builds
  boot.binfmt.emulatedSystems = [ "aarch64-linux" "armv7l-linux" ];

  nix.settings = {
    # Allow building for emulated architectures
    extra-platforms = [ "aarch64-linux" "armv7l-linux" ];
  };
}
```

Rebuild your system:

```bash
sudo nixos-rebuild switch
```

Verify binfmt is working:

```bash
cat /proc/sys/fs/binfmt_misc/armv7l-linux
# Should show: enabled
```

## Building the SD Image

```bash
# Clone the repository
git clone https://github.com/timlinux/tuinix.git
cd tuinix

# Ensure firmware files are in place
ls -la firmware/r36s/

# Build the SD image
nix build .#sd-r36s
```

!!! note "Build Time"
    The first build takes several hours due to limited armv7l binary cache coverage. Subsequent builds are faster as packages are cached locally.

## Flashing the Image

```bash
# Flash to SD card (replace /dev/sdX with your SD card)
sudo dd if=result of=/dev/sdX bs=4M status=progress conv=fsync
```

## Booting

1. Insert the SD card into the R36S (TF1 slot)
2. Power on the device
3. The system will boot to a serial console

### Serial Console Access

Connect a USB-TTL adapter to the R36S serial pins and use:

```bash
screen /dev/ttyUSB0 115200
```

Or with minicom:

```bash
minicom -D /dev/ttyUSB0 -b 115200
```

## Partition Layout

The SD image uses the same partition layout as stock EmuELEC:

| Partition | Size | Format | Content |
|-----------|------|--------|---------|
| sdb2 | 32MB | FAT16 | Boot assets (logos, fonts) |
| sdb5 | 16MB | - | U-Boot environment |
| sdb6 | 32MB | - | Kernel (Android boot.img) |
| sdb7 | 512MB | FAT32 | SYSTEM squashfs (NixOS) |
| sdb8 | ~1GB | ext4 | Storage partition |

## Known Limitations

1. **Stock Kernel**: Uses the vendor Linux 3.4.39 kernel (cannot use mainline due to display driver requirements)
2. **Limited Hardware Support**: Only vendor-provided modules work with the stock kernel
3. **No GUI**: Currently serial console only (display drivers require specific init sequence)
4. **armv7l Cache**: Limited binary cache coverage means longer build times

## Troubleshooting

### Build Hangs or Fails

Ensure binfmt emulation is enabled:

```bash
cat /proc/sys/fs/binfmt_misc/armv7l-linux
```

If not enabled, restart the binfmt service:

```bash
sudo systemctl restart systemd-binfmt
```

### Missing Firmware Error

Ensure all firmware files are extracted:

```bash
ls -la firmware/r36s/
# Should show: bootloader-region.bin, boot-assets.img, uboot-env.bin, boot.img

ls -la firmware/r36s/modules/
# Should show: mali.ko, disp.ko, lcd.ko, gpio-sunxi.ko, udt_joystick.ko, cdc_ether.ko
```

### No Boot / Black Screen

- Check serial console output for error messages
- Verify the SD card was flashed correctly
- Ensure using TF1 slot (primary boot slot)
